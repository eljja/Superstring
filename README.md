## 🚀 Getting Started & Local Execution

### 1. Launching the Interactive Web GUI Locally
Run the lightweight built-in Python server to open the full dashboard in your web browser:
```bash
python run_dashboard.py
```
This serves the application at `http://localhost:8000` and automatically launches your default browser.

### 2. Running Automated Physics Engine Unit Tests
To verify $T$-duality mass invariance, Hodge number topological consistency, and level-matching logic:
```bash
python -m unittest tests/test_solvers.py
```

### 3. Integrating `superstring_db` into External Projects
You can import the database into Python, C++, Rust, Unity, or Unreal physics simulations:

```python
from superstring_db import THEORIES, calculate_kk_winding_mass

# 1. Query Type IIB D-branes & tension formulas
iiB = THEORIES["Type_IIB"]
for brane in iiB.allowed_branes:
    print(f"Brane: {brane.name} | Tension Formula: {brane.tension_formula}")

# 2. Calculate physical mass of a winding Kaluza-Klein state
mass_data = calculate_kk_winding_mass(n=2, w=1, R=3.5, alpha_prime=1.0)
print(f"Physical Mass: {mass_data['mass']} GeV | Level Matched: {mass_data['level_matched']}")
```
